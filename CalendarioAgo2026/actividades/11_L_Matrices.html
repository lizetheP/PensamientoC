   Ejercicios: 

    • La función atributos (matriz) que recibe una matriz de números enteros. La función debe mostrar en pantalla su número de dimensiones (ndim), su forma (shape) y el total de elementos (size).

                

    • La función operaciones (). Realiza los siguiente ejercicios aplicando operaciones con matrices:

    • Ejercicio 1: Suma de matrices. Calcula la matriz resultante Z de sumar las matrices X + Y e imprímela.

      • X = np.array([[1, 2, 3], [4, 5, 6]])

      • Y = np.array([[6, 5, 4], [3, 2, 1]])

    • Ejercicio 2: Resta de matrices. Calcula la matriz resultante C de restar la matrices A y B, empleando la función np.subtract(A, B) e imprímela.

      • A = np.array([[10, 20], [30, 40], [50, 60]])

      • B = np.array([[1, 2], [3, 4], [5, 6]])

    • Ejercicio 3: Multiplicación de matrices. Calcula la matriz resultante M1 de multiplicar las matrices P y Q utilizando la notación compacta (P * Q). Calcula la matriz resultante M2 de multiplicar P y Q utilizando la notación funcional (np.multiply(P, Q))

      • P = np.array([[2, 4], [6, 8]])

      • Q = np.array([[1, 3], [5, 7]])

    • Calcula el arreglo de velocidades por tramo utilizando división real (/) e imprímelo.

    • Ejercicio 4: Registro dinámico. Inicia un arreglo con los tiempos (en segundos) de 4 pruebas de frenado: tiempos = np.array([3.4, 3.1, 3.5, 3.2]) y agrega dos nuevas mediciones [2.9, 3.3] utilizando np.append()

      • tiempos = np.array([3.4, 3.1, 3.5, 3.2])

      • otros = np.array([2.9, 3.3])

    • Guarda el resultado en un nuevo arreglo llamado tiemposf e imprímelo.

                     

    • La función operaciones2 (). Realiza los siguientes ejercicios aplicando operaciones entre un arreglo y un escalar:

    • Ejercicio 1: Ajuste salarial. Dado el arreglo de salarios base de 5 ingenieros: 

      • salarios = np.array([18000, 21500, 19200, 24000, 20500])

    • Calcula un nuevo arreglo llamado salarios_aumento aplicando un incremento del 8% a todos (salarios * 1.08) e imprímelo.

    • Ejercicio 2: Conversiones (F = C / 1.8 + 32). Dado el siguiente arreglo con temperaturas medidas en grados Celsius:

      • celsius = np.array([20.0, 25.5, 30.0, 15.2, 18.8])

    • Calcula el arreglo fahrenheit convirtiendo todo el arreglo celsius a grados fahrenheit mediante la fórmula F = C / 1.8 + 32 e imprímelo.

      • Utiliza la estructura de control if anidada (o if-elif-else). La captura de datos y la validación de la opción elegida deben realizarse dentro de la función main().
      • Utiliza un ciclo while para repetir el programa hasta que el usuario elija la opción de salir.
